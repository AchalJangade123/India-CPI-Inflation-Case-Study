 India CPI Inflation Analysis | Microsoft Excel Project 📊

📌 ######**Project Overview**


This project focuses on analyzing India's Consumer Price Index (CPI) data to understand inflation patterns, price movements, and changes in the cost of living.

The analysis explores Rural, Urban, and Rural+Urban sectors to identify differences in consumer price trends.

Used Microsoft Excel to transform raw data into meaningful insights through data cleaning, data analysis, calculations, and interactive dashboard visualization.

The project demonstrates practical data analytics skills and data-driven decision-making.

🎯 Project Objectives

📈 Analyze India's CPI trends over time.

🌍 Compare inflation patterns across Rural, Urban, and Rural+Urban sectors.

🛒 Evaluate category-wise CPI movements, including Food, Clothing, Health, Housing, and Energy.

📊 Identify monthly and financial-year trends.

🛢️ Explore the relationship between crude oil prices and CPI movements.

💡 Present meaningful insights through Excel dashboards and visualizations.

📂 Dataset Description

📌 Total Records: 375

📅 Time Period: January 2013 – May 2023

🌍 Sectors Covered: Rural, Urban, Rural+Urban

🛒 Categories: Food, Clothing, Health, Housing, Energy, Transportation, Education, and General CPI.

🛢️ Additional Data: Crude oil price information for comparative analysis.
